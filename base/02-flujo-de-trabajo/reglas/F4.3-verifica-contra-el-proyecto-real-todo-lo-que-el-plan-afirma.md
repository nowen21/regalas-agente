## F4.3 · Verifica contra el proyecto real todo lo que el plan afirma

Cada intervención del plan declara **qué**, **cómo**, **dónde**, **por qué** y con qué **impacto**, y cada ruta, firma y dependencia que nombra se comprueba antes contra el proyecto (extiende [`02·F4.1`](F4.1-responde-las-trece-preguntas-en-todo-plan-de-trabajo.md); depende de [`02·F1`](F1-carga-el-contexto-antes-de-actuar.md)). Quedan prohibidas las marcas de incertidumbre —`(o donde esté)`, `(o similar)`, `TBD`, `?`— y los alcances abiertos. Lo que no se pueda verificar **no se escribe como suposición**: se declara pregunta abierta y se espera la decisión del usuario. Cómo se construye la línea base, la matriz de dependencias del refactor y la proporcionalidad del análisis: [`base.md`](../base.md).

```
INCORRECTO: "el archivo de navegación de la carpeta de vistas (o donde esté)"
            → el plan admite que no verificó la ruta real
CORRECTO:   listar la carpeta → localizar el archivo → leerlo → plan dice
            "<ruta real>, sección <X>: agregar el ítem con permiso <permiso.ver>"
```
