> Regla del capítulo [`13 · Documentación`](../base.md).

## DOC20 · No entregues como terminado un documento que todavía trae marcas

Un documento que salió de un modelo y conserva una sola marca `«…»` sin reemplazar no está terminado, y no se presenta como tal: se completa o se dice qué falta y dónde (depende de [`DOC19`](DOC19-marca-con-la-misma-marca-los-espacios-por-llenar.md)). Vale para cualquier documento que una persona vaya a leer como trabajo cerrado, incluida la caja de instrucciones del modelo, que se borra al llenarlo.

```
INCORRECTO: se entrega el plan de trabajo con «estimación» en tres tareas y
            se avisa "después lo completo"
CORRECTO:   se completan las tres, o se entrega diciendo que faltan esas tres
            y que el documento todavía no está terminado
```
