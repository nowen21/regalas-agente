## M11 · Las reglas no se borran: se derogan

Una regla que deja de regir se **marca** `[DEROGADA en X.Y.Z → ver ID]`, no se elimina: se conserva su texto debajo de la marca y su ID **no se reutiliza**. Por qué: [`base.md`](../base.md).

```
INCORRECTO: la regla ya no rige → se borra del capítulo
CORRECTO:   se marca [DEROGADA en X.Y.Z → ver ID] y se conserva su texto debajo
```
