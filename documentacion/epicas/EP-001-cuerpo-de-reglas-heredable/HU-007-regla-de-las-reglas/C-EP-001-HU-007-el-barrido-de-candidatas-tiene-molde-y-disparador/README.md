De dónde sale: el punto 2 del [pendiente 33](../../../../../pendientes/hecho/lo-que-quedo-abierto-en-las-sesiones-viejas.md), abierto desde el 2026-08-06.

**Lo que el usuario pide dos veces ya no depende de que alguien se acuerde.** El barrido de candidatas a regla se había hecho una sola vez, a mano, y quedó sin molde y sin momento fijo: *«sin disparador, se hace cuando el usuario lo pida es un favor, no una norma»*. Ahora tiene [su molde](../../../../../plantillas/candidatas-a-regla.md) y la regla [`20·M20`](../../../../../base/20-meta-reglas/reglas/M20-antes-de-publicar-una-version-se-barre-lo-que-se-pidio-dos-veces.md), que lo exige antes de publicar una versión, que es el único momento del flujo donde hay un tramo cerrado que releer.

**El criterio `CA-06` nació con esta fase**, entre las dos salidas que el pendiente dejó escritas. La otra era una historia propia; se eligió el criterio porque el tema ya tiene dueña.

**Estado:** cerrada el 2026-08-22 (v31.0.0, MAYOR). Veredicto **Cumple**, 5 de 5 casos.
