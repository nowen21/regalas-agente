Baja del [pendiente 87](../../../../pendientes/87-la-estacion-del-commit-casi-nunca-se-marca.md), con las salidas 1 y 3.

**Nadie marcaba la casilla, y no era descuido:** el commit ocurre después de que el trabajo se dio por terminado, y esa es la única casilla que se cumple fuera del momento en que se escribe el documento.

**Lo que apareció al medir:** de los 140 documentos de estado, **106 no tienen la casilla siquiera**. No se les inventa — se cuentan aparte y se nombran.

**Y el costo, dicho de frente:** el hash no existe hasta que el commit está hecho, así que el documento **queda modificado y sin guardar** y entra en el commit siguiente. Las otras dos salidas rompían una regla.
