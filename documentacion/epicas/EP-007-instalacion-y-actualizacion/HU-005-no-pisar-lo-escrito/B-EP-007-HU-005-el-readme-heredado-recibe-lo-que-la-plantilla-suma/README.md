De dónde sale: el punto 8 del [pendiente 33](../../../../../pendientes/33-defectos-que-destaparon-los-resumenes-viejos.md), donde estaba dicho así: «el mecanismo replica y el texto que lo explica no»

**El README heredado ya no se queda viejo.** El `CLAUDE.md` de cada proyecto recibía las secciones nuevas del estándar y el `README.md` del histórico no: quien instaló en julio se quedaba con el texto de julio, y no se notaba porque el archivo existe y dice cosas ciertas, solo que menos. Ahora el instalador lo completa con el mismo mecanismo, sin pisar lo que el proyecto escribió, y lo dice. De paso, la plantilla gana la sección que contesta **qué manda cuando el histórico y lo acordado se contradicen**: manda lo acordado, y el histórico dice de dónde salió.
