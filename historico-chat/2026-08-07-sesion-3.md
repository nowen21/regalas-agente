| Dónde | `target="_blank"` en HTML | Qué sí funciona |
|---|---|---|
| **GitHub / GitLab** | ❌ el sanitizador borra `target` | `Ctrl`+clic → pestaña · `Shift`+clic → **ventana nueva** |

Y ni siquiera con HTML se puede forzar *ventana* en vez de *pestaña* — `target="_blank"` pide "otro contexto" y el navegador elige cuál; casi todos dan pestaña. Forzar ventana solo se logra con JavaScript (`window.open(..., 'popup')`), que en un `.md` del estándar no cabe.

- `validadores/enlaces.py` solo reconoce enlaces markdown `[texto](destino)`. Un `<a href>` se le escapa: si el destino se rompe, nadie se entera.
