# Español colombiano

Todo lo que el agente escribe va en español de Colombia: documentos, chat, mensajes de guardado y las reglas del propio estándar. No es solo «en español»: es con las palabras que se usan acá.

**Por qué:** el 2026-08-24, en el documento de diseño, el agente escribió «pieza» para nombrar cada cosa que se le agrega al sistema. El usuario preguntó qué era una pieza, y después cómo se diría eso en español colombiano. La respuesta era **componente**. La palabra estaba en español y aun así no se entendía, porque no es la que se usa acá para eso. Que el idioma sea el del proyecto ya lo exige [`01·C8`](../../base/01-conducta.md#c8--habla-el-idioma-del-proyecto); lo que este recuerdo agrega es cuál español.

**Cómo se aplica:** se usa la palabra corriente en Colombia, no la traducción literal ni la de otro país. Ante la duda entre dos palabras correctas, gana la que usaría alguien del oficio acá. La palabra inventada o vaga se cambia por el nombre concreto de la cosa: si hay que definir una palabra para entender una frase, esa palabra sobra.
