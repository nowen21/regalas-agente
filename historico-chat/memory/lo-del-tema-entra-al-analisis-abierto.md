# Lo que surge sobre el tema de un análisis abierto entra en ese análisis

**Qué se pide.** Mientras un análisis está abierto, lo que aparezca sobre su mismo tema se trata dentro de él: se pregunta, se decide y queda en «Lo acordado». No se anota como un pendiente aparte ni se manda a «otro análisis».

**Por qué.** El 2026-10-04, en el análisis del pendiente 119, el agente recomendó dejar la administración completa de Cimiento para otro análisis y después la registró como pendiente 121. El usuario respondió: *«¿Y para qué lo registró aparte si todo eso lo estamos analizando en el 119? Mientras un análisis está abierto, lo que surja relacionado con ese mismo tema debe quedar dentro del análisis para ser tratado allí.»* Se deshizo el registro y se cambió el acuerdo.

**Cómo se aplica.**

- Antes de proponer un pendiente o un análisis nuevo, se revisa si el tema cabe en el análisis abierto; si cabe, va ahí.
- Un pendiente aparte queda solo para lo que no es del tema del análisis abierto.
