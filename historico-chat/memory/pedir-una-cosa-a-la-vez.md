# Lo que se le pide al usuario se dice como una sola pregunta, y se dice qué es

**Qué se pide.** Cuando el agente le pasa algo al usuario, tiene que quedar claro **qué necesita de él**: una decisión, una aprobación, o nada. Y si es una decisión, va **una sola**, formulada para responder sí o no.

**Por qué.** Lo dijo el usuario el 2026-08-31: *«y para qué quiere que la vea o es una corrección o necesita que le apruebe algo no es claro»*. Venía de un mensaje donde el agente le mostró un reporte, opinó sobre él, señaló un defecto y ofreció dos trabajos, sin decir en ningún momento qué esperaba de vuelta. El usuario tuvo que preguntar tres veces —«¿qué es?», «¿cómo entro?», «¿qué me aporta?»— antes de que quedara claro que lo único que hacía falta era un sí.

**Cómo se aplica.**

- **Primero lo que se necesita**, y después el contexto. No al revés.
- **Una decisión por vez.** Dos preguntas en un mensaje obligan a responder dos cosas, y se responde una.
- **Si no se necesita nada, se dice**: «esto es informativo». Mostrar algo sin decirlo se lee como un pedido escondido.
- **Nunca mezclar** informar, opinar y pedir en el mismo párrafo: el pedido se pierde entre lo demás.
