# `prompts/analisis/` — qué hacer con cada ficha antes de tocar una regla

Aquí vive el trabajo **sobre** las fichas de [`prompts/`](../README.md): el prompt con que se analizan y el resultado de haberlo aplicado. Las fichas mismas quedan afuera, en la carpeta de arriba.

Es análisis, no norma (`20·M13`). Ninguna regla nace de acá: de acá sale el mapa de qué escribir, y escribirlo es un paso aparte que decide el usuario.

Un análisis es una **fotografía**: vale para la versión del estándar bajo la que se hizo. Si sus hallazgos se ejecutan, se anota en el propio archivo; no se borra ni se reemplaza en silencio.
