Cree la documentación técnica de **cada uno de los archivos existentes**.
La documentación debe construirse **a partir del análisis del código fuente**, no de suposiciones ni de documentación previa.
Para cada archivo:
* Explique cuál es su propósito y responsabilidad.
* Documente cada una de sus **clases, métodos, funciones y atributos**.
* Explique qué recibe cada método o función, qué procesa y qué devuelve.
* Identifique las dependencias que utiliza y las relaciones con otros archivos.
* Describa el flujo de ejecución cuando sea necesario para comprender su funcionamiento.
* Identifique qué archivos dependen de él y de qué archivos depende él.
La estructura debe permitir encontrar fácilmente la documentación correspondiente a cada archivo y comprender, sin necesidad de revisar directamente el código, **qué hace, cómo funciona y de qué otros componentes depende**.
No modifique el código fuente; el objetivo es **documentar fielmente la implementación existente**.
